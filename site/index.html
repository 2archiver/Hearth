Install on your Google TV

Option 1 — On the TV (no computer)

  1. Install Downloader (by AFTVnews) from the Google Play Store on your TV.
  2. Allow Downloader to install apps: Settings → Apps → Security & restrictions → Install unknown apps.
  3. Open Downloader and enter this address, then select Go: 
    https://github.com/2archiver/phairplay-archiver-fork-/releases/download/latest/PhairPlay-googletv.apk
  4. When the download finishes, choose Install, then Open.

Option 2 — From a computer (ADB)

  1. On the TV, enable Developer options by clicking Android TV OS build seven times under Settings → System → About.
  2. Enable USB or Wireless debugging, then find the TV's IP address under Settings → Network & Internet.
adb connect <TV-IP>:5555
adb install -r PhairPlay-googletv.apk

Keep PhairPlay up to date

On the TV, choose Settings → Updates → Check for updates. PhairPlay checks the current GitHub release, verifies its checksum and signing certificate, then offers to install it.

Builds from this repository use the same signing key and normally install over the existing app. A one-time reinstall is needed only when switching from a differently signed build. Update help
