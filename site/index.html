Install it on your TV

Pick whichever is easier — both install the same file.

Easiest — from the TV, no computer

  1. Install Downloader (by AFTVnews) from the Google Play Store on your TV.
  2. Allow Downloader to install apps: Settings → Apps → Security & restrictions → Install unknown apps.
  3. Open Downloader, enter this address, then select Go: 
    https://github.com/2archiver/phairplay-archiver-fork-/releases/latest

    That address opens the release page; Downloader lists its single APK — download that file.

  4. When the download finishes, choose Install, then Open.

From a computer (ADB)

  1. On the TV, enable Developer options by clicking Android TV OS build seven times under Settings → System → About.
  2. Enable USB or Wireless debugging, then find the TV's IP address under Settings → Network & Internet.
adb connect <TV-IP>:5555
adb install -r Hearth-<version>-googletv.apk

Already installed? Just update

On the TV, choose Settings → Updates → Check for updates. Hearth checks the current GitHub release, verifies its checksum and signing certificate, then offers to install it.

Builds from this repository use the same signing key, so updates install straight over the existing app. A one-time reinstall is needed only when switching from a differently signed build. Update help
