Install on your Google TV

Option 1 — On the TV with “Downloader” (no computer)

  1. Install Downloader (by AFTVnews) from the Google Play Store on your TV.
  2. Settings → Apps → Security & restrictions → Install unknown apps → turn on Downloader.
  3. Open Downloader and enter this address, then press Go (it always points at the newest build): 
    https://github.com/2archiver/phairplay-archiver-fork-/releases/download/latest/PhairPlay-googletv.apk
  4. When the download finishes choose Install, then Open.

Option 2 — From a computer with ADB

  1. On the TV: Settings → System → About → click Android TV OS build 7 times, then Settings → System → Developer options → turn on USB debugging (Android 14 also has Wireless debugging).
  2. Find the TV’s IP under Settings → Network & Internet.
adb connect <TV-IP>:5555
adb install -r PhairPlay-googletv.apk

Then

  • Open PhairPlay from your apps row and allow the permission prompts (notifications, nearby devices).
  • On your Mac / iPhone, open AirPlay and pick your TV. Both must be on the same network.
  • Casting works too — PhairPlay ships its own Google Cast receiver, so no Google registration is needed. See the Cast guide for what will and will not cast (YouTube and friends need their own receiver app).

Staying up to date

You install PhairPlay once. After that the app checks GitHub for a newer build in the background, downloads it, and offers a one-tap Update ready — Install prompt on the Home screen. Settings → Updates controls how often it looks and whether it downloads over Wi-Fi only.

Every release is signed with the same key, which is why an update no longer fails with “App not installed as package conflicts with an existing package”.
