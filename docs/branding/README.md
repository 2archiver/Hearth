# Signal Flame

Concept 01: ivory flame, two sweeping signal cuts and coral ember on wine red.
The concept has been reconstructed as vector paths for sharp TV and small-icon rendering.

- `hearth-symbol.svg`: standalone mark.
- `hearth-icon.svg`: legacy launcher tile.
- `hearth-banner.svg`: TV banner master (exported to Android's 320 × 180 banner).
- `hearth-logo.svg`: README lockup.

Android `ic_hearth`, notification mask and adaptive launcher use the same mark geometry.
Adaptive foreground stays inside the launcher safe area; Android 13+ gets a themed mask.
Palette: burgundy `#190B13`, wine `#8E2946`, ivory `#FFF5F7`, coral `#FF7889`.
